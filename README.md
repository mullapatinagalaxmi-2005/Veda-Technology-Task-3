# Veda Technology Internship – Task 3
## Simple Resume Website

### 📌 Project Overview
This project is a professional, responsive, single-page resume website developed as part of the **Veda Technology Web Development Internship – Task 3 (Level 1, Day 3)**.

The website presents my profile, education, technical skills, projects, experience, and contact information using HTML5 and CSS3.

### 🎯 Objectives
- Build a professional personal resume website.
- Use semantic HTML5 to structure content.
- Apply CSS3 for styling and layout.
- Create a responsive design for desktop and mobile devices.
- Practise front-end web development fundamentals.

### 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Visual Studio Code

### ✨ Features
- Profile and About Me section
- Education details
- Technical skills
- Projects section
- Experience section
- Contact information
- Navigation links
- Responsive layout
- Clean and professional design

### 🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.
4. Explore the different resume sections using the navigation menu.
