# Simple Resume Website

## Project Overview
This project is a responsive, single-page resume website developed as part of the Veda Technology Web Development Internship.

The website presents my profile, education, technical skills, projects, experience, and contact information in a professional format.

## Objectives
- Practice semantic HTML5.
- Apply CSS3 styling.
- Create a responsive layout for desktop and mobile devices.
- Organize resume information into clear sections.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Web Design

## Features
- Professional profile section
- Education details
- Technical skills section
- Project descriptions
- Experience section
- Contact information
- Navigation links
- Responsive design

## Project Structure
```text
veda-task-3-resume/
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the resume sections.

## Learning Outcomes
- Understanding semantic HTML elements.
- Styling pages with CSS.
- Using Flexbox and Grid for layouts.
- Creating responsive web pages.
